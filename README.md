# ClientHub - Sistema de Gestao de Clientes

Sistema web completo de cadastro de clientes com autenticacao, CRUD, e dashboard.

## Features
- Login e registro de usuarios (senha com bcrypt)
- Cadastrar, editar, listar e excluir clientes
- Dashboard com estatisticas
- Interface dark premium glassmorphism
- Responsivo (mobile e desktop)

## Stack
- Backend: Node.js + Express + SQLite (better-sqlite3)
- Auth: bcryptjs
- Frontend: HTML5 + CSS3 + vanilla JS
- Deploy: Railway / Render

## Como rodar localmente
\`\`\`bash
npm install
npm start
\`\`\`
Acesse http://localhost:3000

## Deploy
1. Suba pro GitHub
2. Conecte no Railway.app ou Render.com
3. Deploy automatico
